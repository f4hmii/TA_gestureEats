### 4.1.1 Struktur Program
Struktur program sistem Kiosk *Gesture-Eats* dibagi ke dalam beberapa modul utama berdasarkan fungsinya dalam menangani interaksi pelanggan, integrasi sensor (kamera), dan pengolahan data. Masing-masing modul terdiri dari beberapa *file* yang menangani fitur spesifik. Adapun penjelasan struktur program adalah sebagai berikut:

**1. Modul Utama (Core & Entry):** menangani inisialisasi aplikasi, pengaturan antarmuka keseluruhan, dan logika keranjang utama.
*   **main.tsx:** Titik masuk utama (*entry point*) yang bertugas me-render keseluruhan aplikasi React ke dalam dokumen HTML.
*   **App.tsx:** Komponen induk (*root*) yang menggabungkan tata letak halaman Kiosk, menginisialisasi kamera MediaPipe, dan mengelola *state* (status) keranjang belanja secara global.
*   **index.css:** Mengatur gaya tampilan visual (CSS) secara menyeluruh.

**2. Modul API (Komunikasi Server):** berisi kumpulan berkas yang bertugas melakukan permintaan data (*HTTP Request*) dari/ke server *database* Ngolab/Coworking.
*   **client.ts:** Konfigurasi dasar untuk melakukan panggilan ke *server* (pengaturan URL *endpoint*).
*   **digitalBoard.ts:** Menarik data tayangan promo, video, dan iklan untuk ditampilkan saat Kiosk dalam mode menganggur (*Idle Mode*).
*   **menu.ts:** Memanggil dan mengelola data katalog produk (makanan dan minuman) beserta kategorinya dari *database*.
*   **tangolab.ts:** Menangani validasi pemindaian QR Code (Voucher) dan pemrosesan saldo poin pelanggan.
*   **order.ts:** Memproses data keranjang (*checkout*) dan mengirimkannya ke *server* untuk dicatat sebagai transaksi pesanan baru.

**3. Modul Komponen Antarmuka (UI Components):** digunakan untuk membangun elemen visual Kiosk yang rapi dan dapat digunakan berulang kali (*reusable*).
*   **card.tsx:** Membuat bingkai kartu untuk menampilkan gambar produk, nama, dan harga menu.
*   **dialog.tsx & sheet.tsx:** Menampilkan jendela *pop-up* untuk konfirmasi pembayaran QRIS dan bilah geser untuk Rincian Keranjang.
*   **button.tsx & badge.tsx:** Komponen tombol interaksi (seperti "Tambah ke Keranjang") dan label penanda (seperti angka jumlah item).
*   **scroll-area.tsx:** Memfasilitasi area gulir (*scroll*) yang halus pada layar daftar menu Kiosk.

**4. Modul Pemrosesan Sensor (Terintegrasi):** pustaka khusus yang digunakan untuk menangani input dari kamera Kiosk.
*   **MediaPipe Hands:** Modul Kecerdasan Buatan (AI) yang mendeteksi titik sendi tangan pelanggan untuk mengaktifkan sistem kontrol *Air Gesture* (menggerakkan kursor tanpa menyentuh layar).
*   **Html5Qrcode:** Modul pemindai untuk membaca kode batang (Barcode) atau QR Code *Voucher* dari layar HP pelanggan melalui kamera Kiosk.
